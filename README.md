# 📌 E-Commerce Adelis

Hello, this is a project that I developed with three more friends at SENAI. The Adelis e-commerce it's a online thrift store, however, at SENAI we only studied the front-end my team of development only made it the front-end part. 
You can access the website in this link: https://devjuvenilson.github.io/E-Commerce-Adelis/

---

## 🚀 Features

- "Produtos" page that has a button to show more products in our catalog
- "Produto" page that shows product based on which he has clicked in to direct to a payment page.
- The payment page show the subtotal and the product that you've selected.
